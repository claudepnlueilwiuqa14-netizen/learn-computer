# 课堂助教 · 上线部署说明（自定义域名 + 永远在线）

目标：把你验证好用的「每节课本地上下文助教」搬到一台云服务器上，用你自己的域名访问，关电脑也 24 小时在线，像 QQ 那样随时能点开。

---

## 一、谁来做哪一步（先看清边界）

| 步骤 | 谁做 | 说明 |
|---|---|---|
| 租一台云服务器（VPS） | **你** | 要付款 + 你的云账号。拿到 IP 和 SSH 登录方式给我 |
| 注册一个域名 | **你** | 要付款 + 你的注册商账号。拿到域名和 DNS 管理权限 |
| 把域名 A 记录指向服务器 IP | **我**（你授权后） | 或你自己在注册商后台填 |
| 拉代码、配 nginx、上 HTTPS、加访问密码 | **我** | 你给我服务器 SSH 即可 |
| 之后日常使用 | 你 | 浏览器开 `https://你的域名` |

> 我**不能**替你付域名费 / 服务器费，也登不了你的注册商和云控制台（那需要你的账号付款）。但只要这两样到手并把服务器 SSH 给我，剩下全部我来。

---

## 二、费用预估（心里有数）

- **域名**：约 ¥50–200/年（.com / .cn 等，看后缀和注册商）。
- **服务器**：轻量应用服务器 / 小 VPS 约 ¥30–100/月。课堂助手极轻量，最便宜的档就够。
- **AI 调用**：每次问助教都会调 `api.985la.cn`，按该网关计费（具体看它的定价）。永远在线 ≠ 一直烧钱，只有你真正提问时才调用。

---

## 三、推荐选型（你照着买，或让我帮你定）

- **国内**：腾讯云轻量应用服务器 / 阿里云轻量应用服务器（系统选 Ubuntu 22.04/24.04）；域名在阿里云万网或腾讯云 DNSPod 注册。
- **国外**：Vultr / DigitalOcean / 雨云（便宜小机）；域名在 Cloudflare Registrar / Namecheap 注册（Cloudflare 还能顺带白嫖 CDN + 免费证书）。
- 新手最省心：**腾讯云或阿里云轻量 + 同家 DNSPod/万网**，一站式。

---

## 四、你买好之后，把这三样给我

1. 服务器 **公网 IP**；
2. **SSH 登录方式**（root 或某用户的 用户名 + 密码，或 SSH 公钥）；
3. **域名**（以及注册商后台能改 DNS 的权限，通常默认就有）。

拿到后我执行：`ssh 上去 → 跑 deploy/setup.sh → 配 DNS → 验证 https://你的域名 能开`。

---

## 五、部署脚本在做什么（deploy/setup.sh）

在全新 Ubuntu 上 `sudo DOMAIN=你的域名 EMAIL=你的邮箱 ./deploy/setup.sh` 会：
1. 装 nginx + certbot；
2. 把 AI key 写进 `/opt/classroom/.env`（不进代码、不进 git）；
3. 用 systemd 把 `serve_classroom.py` 做成开机自启的常驻服务（崩了自动重启）；
4. nginx 反代 + **Let's Encrypt 免费 HTTPS 证书**；
5. 加一道**浏览器访问密码**（htpasswd）——防止别人白嫖你的 AI key；
6. 完成后 `https://你的域名` 即可用。

---

## 六、安全提醒（重要）

- 上线后**必须**有访问密码（已默认开启）。否则任何人都能拿你的域名无限调用你的 key 让你破费。
- AI key 只在服务器 `/opt/classroom/.env` 里，不在 GitHub 仓库中。
- 想停服务：`sudo systemctl stop classroom.service`；看日志：`sudo journalctl -u classroom.service -f`。

---

## 七、下一步演化（等基础跑通后再说）

现在上线的是「单机 + 文件存记录」版本，能永远在线、有域名、有密码。
要更进一步接近 QQ 级，再逐步加：
- 数据库（Postgres）替代 JSONL，支持多用户 / 换设备记录同步；
- 用户注册登录、权限隔离；
- 手机 / 桌面端。
这些等基础部署稳了，我们再分阶段做。
