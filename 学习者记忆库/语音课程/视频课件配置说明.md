# 视频课件配置说明

课堂视频是辅助材料，不替代老师的双语讲解、英语练习、Lab 证据、检查点和人工验收。视频资源默认只显示官方课程/文档入口；只有配置了 `embed_url` 或 `local_path`，课堂才会在页面内直接播放。

## 最小配置

当前文件：`视频课件配置.json`

本机最近一次只读检查见：`环境配置快照_2026-09-10.md`。它只记录工具是否找到，不代表课程已经学会。

```json
{
  "schema_version": "video-curriculum-v1",
  "enabled": true,
  "default_items": [],
  "items": []
}
```

`enabled` 为 `false` 时，课堂会显示“视频未启用”，但不会影响课程、英语或记忆库。`default_items` 会显示在每一节课；`items` 按课程号前缀、课程类别或明确课号匹配。

## 每个视频条目

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 建议 | 唯一 ID，便于以后替换、统计和复习 |
| `title` | 是 | 页面显示标题 |
| `provider` | 建议 | 来源机构或作者 |
| `kind` | 建议 | `local video`、`embedded video` 或 `official page` |
| `description` | 否 | 为什么和本课有关、看哪一段 |
| `duration` | 否 | 例如 `12 min` 或 `按页面选择片段` |
| `captions` | 否 | 字幕语言和是否需要手动开启 |
| `watch_url` | 否 | 官方页面或视频观看地址；页面会用新标签打开 |
| `embed_url` | 否 | 可嵌入的 HTTPS 地址，例如 YouTube `/embed/...` 或 Vimeo `/video/...` |
| `local_path` | 否 | 相对课堂目录的路径，例如 `videos/PRE0-intro.mp4` |
| `course_ids` | 否 | 只给指定课号显示，例如 `["PRE0", "PRE1"]` |
| `course_prefixes` | 否 | 按前缀显示，例如 `["PY", "NET"]` |
| `categories` | 否 | 按掌握矩阵类别显示，例如 `["web", "security"]` |

## 三种播放方式

### 1. 本地 MP4，最稳定

1. 在课堂目录下建立 `videos` 文件夹。
2. 把自己的合法视频放入其中，例如 `videos/PRE0-intro.mp4`。
3. 在 JSON 中填写 `local_path`，不要填写 Windows 绝对路径。
4. 确认文件是自己制作、已获授权或明确允许离线使用。

示例：

```json
{
  "id": "PRE0-LOCAL-01",
  "title": "我自己的电脑基础演示",
  "provider": "我的本地课件",
  "kind": "local video",
  "local_path": "videos/PRE0-intro.mp4",
  "course_ids": ["PRE0"]
}
```

### 2. YouTube/Vimeo 嵌入

填写平台明确提供的嵌入地址，不要把普通观看页强行当成嵌入地址。某些地区、浏览器或网络会禁止嵌入，此时页面仍保留 `watch_url` 作为备用入口。

示例：

```json
{
  "id": "PY1-EMBED-01",
  "title": "变量基础视频",
  "provider": "授权视频来源",
  "kind": "embedded video",
  "embed_url": "https://www.youtube.com/embed/VIDEO_ID",
  "watch_url": "https://www.youtube.com/watch?v=VIDEO_ID",
  "course_ids": ["PY1"]
}
```

### 3. 官方课程页面

只填写 `watch_url`，课堂显示标题、描述和“打开官方资源”按钮。这是默认方式，最不容易受跨域、地区和播放器策略影响。

## 推荐的配置顺序

1. 先配置 `PRE0` 一个 3–10 分钟本地或官方入门视频。
2. 确认字幕、音量、播放速度和页面缩放适合你。
3. 再为 Python、算法、系统、网络、Web、安全、AI、SRE 各配 1 个官方入口。
4. 每个视频写清观看范围、字幕语言、版本/发布日期和来源授权。
5. 播放后在本课笔记中记录“视频证明了什么、没有证明什么”；不以播放次数自动解锁关卡。

## 需要你配置的整个平台清单

### 必须配置

- Windows 电脑可以正常打开 PowerShell。
- Python 3.10 或更高版本，并确保 `python --version` 有输出。
- 使用启动脚本运行平台：`启动课堂模式.ps1`。
- 通过 `http://127.0.0.1:8765/学习主页.html` 访问，不使用 `file:///`。
- 保留 `学习者记忆库` 文件夹的读写权限，用于保存回答、英语练习和 Lab 证据。
- 定期备份整个 `学习者记忆库`，至少保留一个外部备份和一个历史版本。

### 视频配置

- 选择本地 MP4、合法的嵌入地址或官方页面。
- 确认视频有英文字幕；中文解释由课堂页面和老师补充。
- 检查视频版权、地区可用性、嵌入权限和音量。
- 不把私人视频、带密码视频或他人未授权文件放入配置。
- 大视频优先放在本地 `videos/`，不要把绝对路径写进页面。

### 英语与声音

- 浏览器允许当前本地页面播放声音。
- 如果使用浏览器语音，系统安装英文（优先 English United Kingdom）和中文语音包。
- 每次课堂直接使用页面输入框完成拼写、改写和错误类型记录；草稿会保存在本机。
- 云端 TTS 或语音服务需要单独的账号、费用、隐私和网络配置；不要把 API Key 写进课程文件。

### 实验工具

- Python：解释器、`venv`、测试工具和 Git。
- C/C++/Rust/Java/Go/Node.js：按进入对应轨道时再安装，不必第一天全部安装。
- 数据库：先用 SQLite，进入 DB 高阶课再配置 PostgreSQL。
- 网络：浏览器开发者工具；Wireshark 只抓自己的设备/回环/授权环境。
- 容器/云：进入 OPS 课再配置 Docker、WSL 或本地虚拟机；课程不会要求直接改生产系统。
- 安全：只使用自有代码、合成数据、隔离实验室、CTF 或明确授权靶场。

### 记录与备份

- 每次提交包含日期、环境、命令、输出、退出码、解释、清理和未验证项。
- 不在回答、截图、视频或日志中写入密码、Cookie、API Key、真实凭据或他人个人信息。
- 每十节课从主页生成一次个人成果报告。
- 发现错误时保留原始证据，新增修订记录，不覆盖历史记录。

### 可选增强

- 配置一台大屏或第二显示器，用于同时看视频和做实验。
- 使用耳机、字幕和 0.75–1.0 倍速，减少听力负担。
- 使用 Git 私有仓库保存自己的代码和笔记，并另做离线备份。
- 术后疲劳、手部不适或注意力下降时暂停；平台不设置断签惩罚。

## 安装顺序与核验命令

不要一开始把所有语言和云工具全部安装。按下面顺序逐层增加，任何一步失败都先记录错误，不要反复盲目重装。

### 第 1 层：零基础编程

先安装 VS Code 和 Git。核验：


虚拟环境只用于课程实验，不要把系统 Python 删除或覆盖。完成 PRE0–PRE8 后再安装 Python 扩展、调试器和测试工具。

### 第 2 层：Python 工程

```powershell

python -m pip install pytest ruff mypy

```

安装包前记录 Python 版本、安装日期和网络来源；课程记录只保存工具版本，不保存账号令牌。

### 第 3 层：其他语言（进入对应轨道再装）

| 轨道 | 工具 | 核验命令 |
|---|---|---|
| C/C++ | Visual Studio Build Tools 或 LLVM/Clang | `cl` 或 `clang --version` |
| Rust | rustup + stable toolchain | `rustc --version; cargo --version` |
| Java | JDK 21 或课程指定 LTS | `java --version; javac --version` |
| JavaScript/TypeScript | Node.js LTS | `node --version; npm --version` |
| Go | Go stable | `go version` |
| Shell | PowerShell；需要时再加 WSL | `$PSVersionTable.PSVersion`、`wsl --status` |

不需要在第一天同时安装这些工具。课程到达对应课号时，老师会给出当时版本和最小安装范围。

### 第 4 层：数据、网络和系统实验

- SQLite：通常随 Python 或工具可用，先用它完成 DB 入门。
- PostgreSQL：进入数据库高阶课时再安装，并只建立本地学习账号和本地数据库。
- Wireshark：只抓自己的设备、回环接口或明确授权的实验流量；安装后先核验 `tshark --version`。
- WSL/Docker/虚拟机：进入系统、容器和 SRE 课时再配置；先确认磁盘空间、内存和可恢复快照。

### 第 5 层：语音和视频增强

浏览器语音不需要 API Key。若要生成离线双语音频：

```powershell
python -m pip install edge-tts
ffmpeg -version
python .\generate_voice_lesson.py --input .\PRE0-第一段.json --output .\PRE0-第一段.mp3
```

网络语音服务可能因地区、网络或服务策略失败；失败时使用浏览器语音回退，不把失败伪装成已生成。视频先使用官方页面链接，确认可用后再配置嵌入地址或本地 MP4。

6. 英语练习能提交，错误能分类为拼写、语序、语法或词义/回忆。

8. 机器基线通过不等于学习者掌握；关卡、Lab、Boss 和毕业工程必须由你的证据和老师验收决定。
