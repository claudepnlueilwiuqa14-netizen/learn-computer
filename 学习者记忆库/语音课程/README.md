# 双语语音老师模式

本课程现在支持三种互补的授课表面：

1. **实时 Voice**：在 ChatGPT Windows 桌面版点击 Voice，老师可以边说边显示文字；你可以随时打断、提问或让老师放慢。
2. **双语音频课**：每个知识片段先用英式英语讲，再用中文复述和解释；英文术语保留在字幕中，方便建立计算机英语词汇。
3. **文字证据课**：命令、输出、答案和验收仍然落在课程证据目录，语音不能替代学习者实验证据。

## 课堂声音协议

- 英语声线：`en-GB-RyanNeural`，目标是清晰、稳定、偏英国英语的教师口吻。
- 中文声线：`zh-CN-YunyangNeural`，用于紧跟英语后的中文解释。
- 每个知识点顺序固定为：英文讲解 → 中文翻译 → 术语慢读 → 一个问题或动作。
- 默认每段 20–90 秒，然后停下来等待你回答；不连续自动播放整天课程。
- 你可以说：`慢一点`、`再说一遍英文`、`只讲中文`、`解释这个词`、`暂停做题`、`继续`。
- 长时间学习按 15–25 分钟一小节，中间允许休息；术后身体不舒服时立即暂停。

## 语言目标

英语不是额外考试，而是计算机世界的工作语言。每节课只固定少量高频词，例如：

| English | 中文 | 本课用法 |
|---|---|---|
| input | 输入 | 键盘或鼠标送进电脑的信息 |
| process | 处理 | CPU 对信息执行操作 |
| memory | 内存 | 临时工作空间 |
| storage | 存储 | 长期保存文件的地方 |
| output | 输出 | 屏幕或音箱展示的结果 |

## 隐私与网络

生成音频需要把本课文本发送给语音服务；不把密码、Cookie、API Key、真实个人数据或第三方机密放入语音脚本。课程证据仍保存在本地。

## 视频与平台配置

课堂页面现在有“视频辅助”区域。资源配置在 `视频课件配置.json`，支持官方页面链接、合法的 YouTube/Vimeo 嵌入地址和 `videos/` 目录中的本地 MP4/WebM。字段、匹配规则、安装顺序、当前环境状态和备份要求见 `视频课件配置说明.md` 与 `环境配置快照_2026-09-10.md`。视频播放只建立直觉，不自动解锁关卡或改变学习者掌握状态。

## 生成器

`generate_voice_lesson.py` 接收一个 JSON 课堂脚本，生成 MP3 和可人工核对的逐段文本。示例：

```powershell
python .\语音课程\generate_voice_lesson.py `
  --input .\语音课程\PRE0-第一段.json `
  --output .\语音课程\PRE0-第一段.mp3
```

## 断网和关机

双击本目录中的 `启动离线课堂.cmd`，或双击上级目录 `启动离线课堂.cmd`，即可启动本机课堂并打开学习主页。课程目录、双语课件、英语练习和学习记录都在本机；断网不影响这些内容。云端老师思考、远程视频和云端语音需要网络，失败时页面会保留本地内容并提示稍后重试。

关机前无需额外保存。回答、英语练习和证据会使用原子 JSON 保存与逐条刷盘；建议定期双击 `学习者记忆库\\备份学习记录.cmd`，在同级的 `学习者记忆库备份` 下保留带时间戳的多个版本。完整说明见 `..\\离线使用说明.md`。
