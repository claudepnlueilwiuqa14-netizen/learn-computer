# learn-computer

590 节计算机宗师课程：从完全零基础到计算机学术研究。课程同时包含计算机知识、平台内英语训练、双语课堂、闯关验收、Lab 实战和离线本地服务。

## 打开课程

1. 安装 Python 3.10 或更高版本。
2. 双击 `学习者记忆库/语音课程/启动离线课堂.cmd`。
3. 浏览器打开 `http://127.0.0.1:8765/学习主页.html`。

也可以在 PowerShell 中运行：

```powershell
cd .\学习者记忆库\语音课程
python .\serve_classroom.py --root . --port 8765
```

然后打开 `http://127.0.0.1:8765/学习主页.html`。课程内容、590 节目录、英语课件和课堂网页均在仓库中；云端老师思考、远程视频和云端语音需要网络，本地文字课堂和本地记录不依赖互联网。

## 目录

- `学习者记忆库/语音课程/`：课堂网页、本地服务、英语课件、590 节 HTML 目录和离线启动文件。
- `逐课专属深度合同_590课.json`：逐课结构化课程合同。
- `逐课专属深度合同_590课.md`：可阅读的逐课课程合同。
- `教案_总索引.md`、`完整课程安排.md` 和 `方向*.md`：总规划、八大方向教案和实战补强。
- `核验*.ps1`：课程结构、Lab 和毕业工程核验脚本。

## 隐私说明

本公开源码仓库不包含个人学习记录、浏览器 Cookie、密码、API Key、记忆库备份或本机证据目录。学习记录应保存在本机的 `学习者记忆库/课堂记录/`，不要提交到公开仓库。
